# TaskDec 摘要初稿

日期：2026-09-17。按作者指定顺序组织：应用背景 → 问题 → 架构 → 方法 → 效果 → 开源。当前为中文讨论稿，依据已完成实验撰写。

工作标题：**TaskDec: Task-Aware Decoupled Fusion for Multi-Sensor 3D Object Detection**

## 中文摘要

融合相机、LiDAR 与四维雷达的互补观测，是提升自动驾驶三维目标检测能力的重要途径。然而，空间对齐后的多模态特征仍混合着共同信息、模态特有线索和背景响应，如何在利用跨模态一致性的同时保留有益差异，并使二者的融合受到目标相关性引导，仍是一个关键问题。为此，本文提出 TaskDec，一种将表征解耦与目标相关交互联合建模的任务感知融合架构。具体而言，TaskDec 在对齐的局部空间中学习共享与模态特有表征，并通过目标区域内的表征约束组织跨模态一致性与差异性。在此基础上，架构结合前景门控、模态控制与目标上下文，调制传感器输入特征、跨模态注意力查询及融合输出，使解耦表征直接参与检测表示的构建。K-Radar 实验表明，在 v1 的相同置信度过滤设置（conf=0.3）下，TaskDec 相对官方 ASF 权重对应结果的 AP3D@0.3 和 APBEV@0.5 分别提高 8.04 和 7.77 个百分点，参数量仅增加约 1.7%。组件消融与表征、空间门控分析进一步支持该设计的有效性；其解耦控制变体在 v2 宽域双类别设置下，也取得了相对同训练日程 ASF 的检测收益。代码与模型将公开发布。

## 参考摘要的组织方式

- [ASF](https://arxiv.org/abs/2503.07029)：从多传感器融合价值进入可用性与表征问题，接核心设计，再报告定量收益和代码地址。
- [3D-LRF](https://openaccess.thecvf.com/content/CVPR2024/html/Chae_Towards_Robust_3D_Object_Detection_with_LiDAR_and_4D_Radar_CVPR_2024_paper.html)：先描述检测需求和融合不足，再依次解释空间交互与条件门控，最后概括实验表现。
- [L4DR](https://arxiv.org/abs/2408.03677)：将数据质量差异、天气退化两个问题对应到编码与特征融合设计，然后给出效果。
- [WCBR 公开版](https://arxiv.org/abs/2604.05405)：从条件变化进入问题重述，再解释多分支表示、路由与监督，最后报告实验及开放计划。这里只参考组织方式，不沿用其旧版固定融合、语义提示或强可解释性表述；另核对了[本地修订草稿](../../WCBR/wcbr_icra_pdf_full_revision_review_260910.md)。

## 数值与措辞依据

- v1 数值、差值和参数量来自[全文证据总稿](taskdec_full_paper_evidence_motivation_contributions_260917.md)及其中原始 JSON。8.04 按原始精度相减，未沿用旧稿舍入后得到的 8.05。
- `conf=0.3` 保留在当前定量句中，因为对官方 ASF 的大幅差值依赖置信度过滤设置。该句不声称全面超过 ASF 官方论文值或本地重训 ASF。
- v2 使用 DecControlled Strong，缺少 task-context 分支，所以写“其解耦控制变体”，不写成完整 TaskDec 在另一数据集上的收益。具体增益见[v2 报告策略](taskdec_v2_reporting_strategy_260916.md)。
- V2X 2×2 尚未完成，当前完成的 4×4 低于 Concat；摘要暂不作多数据集一致领先的结论。最终跨数据集结论应依据完整结果更新。
- “代码与模型将公开发布”是拟用的未来发布声明，不表示已经开源；尚无已核验的 TaskDec 投稿代码链接，不虚构仓库地址。投稿时可替换为“代码与模型将在［待补代码链接］公开”。
